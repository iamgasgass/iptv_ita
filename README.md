# Lista IPTV Italiana

 **Lista IPTV con solo canali Italiani in chiaro con Guida TV (EPG) annessa.**

## Features

- 📺 Canali Italiani
- 📅 Guida TV (EPG)


1. Scaricare l'elenco dei canali.
2. Importare la lista nella tua app IPTV preferita o in alternativa 

## Installazione alternativa 

- Copiare e incollare il seguente link nella tua app IPTV preferita:
—> "[[https://github.com/iamgasgass/iptv_ita/raw/branch/main/lista.m3u](https://github.com/iamgasgass/iptv_ita/blob/main/lista.m3u)](https://raw.githubusercontent.com/iamgasgass/iptv_ita/refs/heads/main/lista.m3u)"

## Guida tv

La guida tv è offerta dal progetto "epgshare01"
- Per utilizzarla copiare e incollale il seguente link nel vostra player preferito:
—> "https://epgshare01.online/epgshare01/epg_ripper_IT1.xml.gz"

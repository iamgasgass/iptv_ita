# Lista IPTV Italiana

 **Lista IPTV con solo canali italiani in chiaro con guida tv (epg) annessa.**

## Features

- 📺 Canali Italiani
- 📅 Guida TV (EPG)



1. Scaricare l'elenco dei canali.
2. Importare la lista nella tua app IPTV preferita o in alternativa 

## Installazione alternativa 

1. copiare e incollare il seguente "https://forgejo.it/peppenamir/iptv_italia/raw/branch/main/lista.m3u" nella tua app IPTV preferita"

## Guida tv

La guida tv è offerta dal progetto "epgshare01" per utilizzarla copiare e incollale il seguente link nel vostra player preferito "https://epgshare01.online/epgshare01/epg_ripper_IT1.xml.gz"
